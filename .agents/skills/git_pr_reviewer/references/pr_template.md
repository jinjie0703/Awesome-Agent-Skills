# 📋 大厂级 Pull Request (PR) 审查与提交描述模板

---

## 模板：Pull Request 描述标准骨架

```markdown
## 📌 概述 (Summary)
[简述本次 PR 解决的核心问题、业务背景或功能亮点]

---

## 🛠️ 变更清单 (Key Changes)
- **核心特性 / 修复**: 
  - `模块 A`: [具体变动描述]
  - `模块 B`: [具体变动描述]
- **架构与依赖**: [是否有新增依赖或架构调整]

---

## 🛡️ 安全与合规自检 (Security & Quality Checklist)
- [x] **无敏感密钥泄露**：经 `git_diff_inspect.py` 扫描，无 API Key、私钥或内网密码泄露；
- [x] **无调试残留**：已清理临时 `console.log`、`print()` 与断点；
- [x] **向后兼容性**：[无破坏性变更 / 存在 Breaking Change 并附说明]；
- [x] **单元测试覆盖**：[本地已通过全部测试用例 / 新增了测试覆盖]。

---

## 🧪 验证方式 (How to Verify)
1. 运行命令：`[验证命令]`
2. 预期输出：`[成功结果]`
```
